# Recomputing the paper's results from scratch

The figure and table scripts named in `README.md` read stored results from the data archive.
This file lists, for each paper item, the scripts that write those results, in the order to run them; the last script of each list is the one that prints or draws the item.
Each script's header names its inputs, outputs and seeds.
Arguments follow the path; times are those the headers give, on the number of workers they state ("not timed": the header gives none).

Almost everything in the game starts from `experiments/run_signaling_architectures.m` (several hours on 4 workers), which evolves the 100 populations of each signaling architecture.
Lists below that say "after the architectures" begin with it.
